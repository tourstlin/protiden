# 硬件设计（下位机拓展板）

下位机的电路是自己画的 PCB，设计在 **嘉立创 EDA（专业版）** 上完成，
走「在线设计 → 一键打板 / SMT」链路。

**这是一块 Ø98mm 的圆形板**，用于台灯底座：中间插一块 STM32 最小系统板，
四周布置电源、灯驱动、传感器、蓝牙、OLED。

本目录存放**导出物**，仓库因此是自洽的——不用登录 EDA 平台也能看懂料单、
直接拿 Gerber 去打板；源工程保留在 EDA 里方便继续改。

## 板卡规格

| 项 | 值 |
|---|---|
| 外形 | **圆形 Ø98mm**（板框为一个整圆） |
| 层数 | **双层**（无内层） |
| 过孔 | 183 个（0.3 / 0.6mm） |
| 插件孔 | 249 个（0.3 ~ 2.3mm，8 种刀径） |
| 实体元件 | 28 个 |
| 飞针测试点 | **108 个**（`PAD1~PAD108`，用于工厂飞针测试） |
| MCU | 不焊在板上，通过 **H2/H3 两个 20pin 母座**插 STM32F103C8T6 最小系统板 |

> 板厚、铜厚、阻焊/丝印颜色、表面处理等**工艺参数不在 Gerber 里**，
> 下单时在板厂页面自行选择（本项目按常规双层板打样）。

## 关键器件

| 位号 | 器件 | 作用 |
|---|---|---|
| H2 / H3 | 20pin 母座 ×2 | 插 STM32 核心板（左排含 VBAT/PC13-PC15/PA0-PA7/PB0/PB1/PB10/PB11/NRST，右排含 PB3-PB9/PA8-PA12/PA15+电源） |
| DHT-11 | 温湿度传感器 | 数据脚 → **PA12** |
| HC-05 | 蓝牙串口模块 | RXD/TXD → **PA10 / PA9**（USART1，9600） |
| OLED1 | 0.96" I2C OLED | SCL/SDA → **PB8 / PB9** |
| Q4 | N-MOSFET | 调光管：栅极经 R1 ← **PB7**（TIM4_CH2，10kHz） |
| R1 / R2 | 电阻 | 栅极电阻 / 栅极下拉 |
| 蜂鸣器 | 有源蜂鸣器 | **PB6** 驱动 |
| DC1 | DC 电源座 | 输入 → F1（自恢复保险丝）→ SW1（开关）→ VIN |
| U6 / L1 / D1 | DC-DC 降压 | VIN → 5V（L1 储能电感，D1 续流二极管） |
| F1 / F3 | 自恢复保险丝 | 输入保护 / 5V 输出保护 |
| H1 | 4pin 排针 | 5V / GND 输出 |
| SW1 | 自锁开关 | 总电源开关 |
| C1-C5, C17-C20 | 电容 ×9 | 去耦 / 滤波 |

完整清单（含飞针坐标）见 [`bom.csv`](bom.csv)；
**固件端对应的引脚分配**见 [`../firmware/README.md`](../firmware/README.md)。

## 自己打板

Gerber 已就绪，两种方式：

1. **直接用现成压缩包**：把 `gerber/protaiden-v2.0-gerber.zip` 上传到任意板厂
   （嘉立创下单页 → 上传 Gerber → 选工艺参数 → 下单）
2. **自己改板再打**：需要源工程——按下面步骤从嘉立创 EDA 导出 `.epro`，
   拖进编辑器（**文件 → 导入 → 嘉立创EDA(专业版)**）即可编辑

## 导出源工程（需在嘉立创 EDA 里操作）

### 1. 源工程归档 `.epro`

编辑器内：**文件 → 另存为 → 工程另存为(本地)** → 保存出 `.epro` 文件。

> ⚠️ **不要勾「加密」**。设了密码后，其他客户端导入时会直接报错打不开。
>
> 网页版批量导出：编辑器左侧**工程列表右键 → 工作区打开 → 查看所有工程 → 批量下载专业版**。
> 离线客户端的工程默认在 `文档/LCEDA-Pro/projects`（`.eprj` 格式），也可装
> `export-design-archive.eext` 插件批量导 `.epro`。

### 2. 原理图 PDF

打开原理图页：**文件 → 导出 → PDF/图片** → 存成 `schematic.pdf`。

### 3. BOM（可选）

原理图页：**文件 → 导出 → 物料清单(BOM)** —— 本目录的 `bom.csv` 已由飞针文件生成，
补上型号列后可以替换它。

## 在线查看 / 开源到立创广场

源工程除了放进仓库，还建议**同时发布到[立创开源硬件平台](https://oshwhub.com)**——
硬件圈的人都在那儿，能被人搜到、被「克隆」复刻，还能参加官方的免费打样活动。

**发布流程**：登录后右上角 **「发作品」→ 开源工程 → 下一步 → 选中你的工程 → 去编辑** →
填封面（建议用实物照片，其次 PCB 3D 预览图）、**选开源协议**、加标签（最多 3 个）、
写简介（≤100 字）与描述 → **添加附件**（可以把上位机代码、固件、接线说明一起挂上，
单文件 ≤50MB）→ **发布并分享**，等审核通过即可。

**许可证怎么选**（平台提供的选项里，推荐这三个）：

| 协议 | 适用 |
|---|---|
| **CERN Open Hardware License** | 硬件领域最"正统"的开源硬件协议，含专利授权条款，最专业 |
| **CC-BY-SA 3.0** | 好理解、允许商用，要求署名 + 相同方式共享 |
| **MIT** | 最宽松，和软件侧许可证同族，允许闭源再发布 |

> ⚠️ **别选 `CC-BY-NC*` 系列**（非商业限制），那不算开源，别人也不能拿去做产品。
